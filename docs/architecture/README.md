## 🎯 架构目标

1. **认知减负**：主模型不再需要理解任务调度、状态管理、模式切换
2. **模块解耦**：子智能体作为黑盒工具，可独立升级和优化
3. **自然交互**：使用自然语言作为工具接口，降低使用门槛
4. **结果导向**：主模型只关心返回结果，不关心内部实现

## 🔄 新旧架构对比

```
┌─────────────────────────────────────────────────────────────┐
│                      旧架构 (Subagent)                        │
├─────────────────────────────────────────────────────────────┤
│  Parent Agent ───► new_task() ───► Child Agent              │
│       ↑                                  │                  │
│       └──── attempt_completion() ◄───────┘                  │
│                                                             │
│  痛点：                                                      │
│  • 父任务需要理解如何委派、构建子任务上下文                        │
│  • 需要管理状态转换：active → delegated → active               │
│  • 需要理解不同模式的适用场景                                   │
└─────────────────────────────────────────────────────────────┘

                          ↓ 演进 ↓

┌─────────────────────────────────────────────────────────────┐
│                    新架构 (Agent as Tools)                    │
├─────────────────────────────────────────────────────────────┤
│  Main Agent ───► searchProject("调查项目结构")                 │
│             ───► applyEdit("修复这个bug")                      │
│             ───► consultExpert("设计最优架构")                 │
│                                                             │
│  优势：                                                       │
│  • 工具化封装，主模型无需理解内部实现                             │
│  • 自然语言接口，降低认知负担                                   │
│  • 结果导向，专注于任务本身                                    │
└─────────────────────────────────────────────────────────────┘
```
