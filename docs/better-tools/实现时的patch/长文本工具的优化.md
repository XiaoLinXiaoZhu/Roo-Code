## 新增 update_todo_list 的 Markdown 格式支持

### 背景

`update_todo_list` 工具的 `todos` 参数是多行 markdown checklist，使用 JSON 格式需要大量 `\n` 转义，增加了 token 消耗和模型输出错误率。

### 实现要点

#### 1. 无路径参数工具的支持

与 `write_to` 和 `apply_diff` 不同，`todo_list` 工具不需要路径参数。需要在 `MarkdownToolParser.ts` 中：

- 新增 `MARKDOWN_TOOLS_WITHOUT_PATH` 常量标识不需要路径的工具
- 修改 `parseHeader()` 方法，对于无路径工具只解析工具名
- 格式：` ```todo_list\n内容\n``` `（没有路径）

#### 2. Task.ts 中的流式处理

**关键问题**：`Task.ts` 中处理 Markdown 工具事件时，需要根据工具类型设置不同的参数：

```typescript
// tool_start 事件
if (mdEvent.toolName === "update_todo_list") {
	params = { todos: "" }
} else {
	params = { path: mdEvent.path, content: "" }
}

// tool_delta 事件
if (toolUse.name === "update_todo_list") {
	toolUse.params.todos = (toolUse.params.todos || "") + mdEvent.contentDelta
} else {
	toolUse.params.content = (toolUse.params.content || "") + mdEvent.contentDelta
}

// tool_end 事件
if (toolUse.name === "update_todo_list") {
	toolUse.nativeArgs = { todos: toolUse.params.todos || "" }
} else if (toolUse.name === "write_to_file") {
	toolUse.nativeArgs = { path, content }
} else if (toolUse.name === "apply_diff") {
	toolUse.nativeArgs = { path, diff: content }
}
```

#### 3. 易错点

- **遗漏 nativeArgs 设置**：`BaseTool.handle()` 会检查 `block.nativeArgs !== undefined`，如果没有设置会抛出 "missing nativeArgs" 错误
- **参数名不匹配**：`update_todo_list` 使用 `todos` 而不是 `content`，需要在所有相关位置保持一致
